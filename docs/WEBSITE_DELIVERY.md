# MLBench Studio 网站交付说明

## 启动与日常使用

安装 README 所列依赖后，双击根目录的“启动本地实验台.bat”。脚本检查前后端均能访问后才会报告就绪。访问 `http://127.0.0.1:5173/mlbench-studio/`。服务仅监听本机地址。

默认首次实验使用 Iris 与 KNN，便于快速验证。Scratch SVM 的核训练较慢；查看 Moons / Circles 边界时可先选择 sklearn 对照，再运行 Scratch 比较。界面中的模型计算耗时是训练与预测时间之和，另显示包含排队与图表的实际耗时。

## 可视化及读图规则

所有数值来自真实训练输出。多次运行时，顶部指标是每次评价指标的均值与标准差；图表展示第一次种子、第一折的代表性运行，并明确标注来源，混淆矩阵不冒充平均矩阵。训练集负责确定投影方向，测试集只映射到该坐标系。

- 通用分类：混淆矩阵、真实与预测分布、二维测试投影。可输出概率的模型还有单样本概率；适用的二分类另有 ROC。
- Linear Regression：真实值与预测值、残差散点与零线、残差分布、系数贡献。
- Logistic Regression：分类图、系数贡献；Scratch 另显示实际记录训练轮次的损失曲线。
- KNN：选择前 40 个测试样本之一，调节演示 K，观察真实近邻距离和投票。距离使用全部预处理特征，二维线段仅辅助展示。演示不修改正式结果。
- Naive Bayes：分类图、类别概率、前四个特征的模型高斯密度，可切换特征。密度来自训练均值与方差，不代表经验分布。
- SVM：Moons / Circles 的实际二维特征上，显示真实预测区域、decision function 零边界与去重支持向量。高维数据只显示 PCA 投影，并明确提示其不是决策边界。
- Decision Tree：真实特征名与类别名，默认前四层；截断处标注仍有子节点，可切换至六层，滚动、悬停或放大查看。Scratch 与 sklearn 均支持。
- Random Forest：分类图、特征贡献、同一个已训练森林的前 N 棵树测试准确率。两个实现对默认随机候选特征都使用 sqrt。
- Gradient Boosting：分类图、树分裂统计（可获得时）、训练损失（Scratch）与逐轮测试准确率。
- K-Means：Scratch 支持逐轮播放、滑动、单步与暂停。样本标签、质心、簇规模和 Inertia 均对应所选轮次。sklearn 不输出迭代历史时，仅展示最终结果，不生成模拟轨迹。
- PCA：全部保留主成分的解释方差谱、累计解释方差曲线和测试集投影。二维投影不展示第三个及之后的主成分。

每张图可放大。SVG 下载保留真实绘图内容，可直接用于报告或转换为图片。大矩阵和树在自身区域滚动，不扩大整个页面。误判、残差、概率、分裂次数和系数应按各自含义解释，不能混为因果贡献。

概率图与 KNN 样本使用上一个、编号跳转、下一个切换，不再展开长列表。柱宽按数据间距确定，自动范围保留首尾柱的空间；所有图形受绘图区裁剪，坐标文字位于数据图层之上。逐折明细的所有表头与数值居中，Benchmark 仅保留算法名称列左对齐，其余列标题与指标居中。

## Benchmark 使用

打开导航的 Benchmark，选择算法、数据集、实现版本、种子和重复次数。程序逐项实际运行，不兼容组合自动跳过。“完成当前后停止”保留已完成记录；离开页面也会在当前实验结束后停止后续批量任务。

热力图按分类、回归、聚类、降维分别显示，并要求相同划分、预处理、评价策略、重复次数和起始种子。聚类额外分组 K，PCA 额外分组保留维数。每个模型、实现与数据集仅展示当前条件下最新的运行，空格表示没有运行。每列颜色仅在该数据集上比较；不同数据集上的 Accuracy 不构成统一排名。模型参数保存在详情中；选择不同参数时需在报告中解释。

同一已训练集成的逐步测试曲线只用于解释机制，不应反复用测试集挑超参数。正式调参应使用训练集内部验证，最后保留独立测试集。标准差不等于置信区间。

## 保存与恢复

完整结果使用浏览器 IndexedDB 保存，摘要使用 localStorage。超额写入失败会明确提示，成功实验仍可查看与下载。前端恢复时把 Vue 响应式对象转换成普通快照，避免 IndexedDB 克隆失败。

运行记录页可导出筛选后的完整实验集合，或导出指标 CSV；JSON 可导入另一浏览器。每次实验还保存原始配置与表单配置，可按原配置重新运行。CSV 包含种子、评价方法、重复次数、均值、标准差与向量指标，Excel 可正常读取。

正在运行的后端任务 ID 会保留在浏览器中；刷新后可恢复 WebSocket / HTTP 查询。后端结果存入 `tmp/experiments.sqlite3`，可通过环境变量 `MLBENCH_HISTORY_DB` 改变位置。后端在训练中重启时，该训练不会自动继续，会给出明确失败原因；已完成记录仍可按 ID 读取。

浏览器和后端历史均是本机数据，Git 仓库不包含用户实验数据库。备份 JSON 是跨电脑保存结果的直接方式。公开 GitHub Pages 提供静态前端展示，真实训练需要运行本地后端或另行部署 Python 服务。

## 验收覆盖

后端测试覆盖十种算法、四种任务、统一接口、多种子和交叉验证，以及投影方向、真实 SVM 边界、KNN 全维距离、集成检查点、K-Means 每轮标签、系数贡献轴、参数预校验和 SQLite 恢复。运行 `python -m pytest backend/tests -q`。

`scripts/browser-delivery-qa.py` 与 `scripts/browser-delivery-edgecases.py` 是本地 Edge CDP 验收脚本，需要先启动独立测试浏览器，开启本机调试端口 9230。这两个脚本只用于开发验收，普通使用不需要调试浏览器。截图、下载文件与验收 JSON 存在 `tmp/delivery-qa/`，不上传 Git。

`scripts/browser-chart-layout-qa.py` 另外检查真实二分类、三分类和十分类概率图的 SVG 柱边界、裁剪与图层顺序，核对样本切换后的柱高和后端概率，测量六列表格表头与数值的中心线，并检查 100%、125% 和窄屏截图。排版验收产物在 `tmp/chart-layout-qa/`。

实际验收包括 Iris、Digits、Two Moons、Wine、Diabetes 的网页训练、六组批量实验、矩阵归一化、K-Means 播放、KNN 调 K、树真实类别名、SVG 与完整数据下载、JSON 导入、刷新、存储限额、WebSocket 无响应兜底、参数错误提示和窄屏布局。

本轮完整后端测试为 60 项通过，前端 TypeScript 与生产构建通过，8 个数据集的三随机种子代表链路通过。浏览器验收无未捕获的页面异常；失败场景包括 WebSocket 静默和无法创建、接口失败、负数种子、存储配额不足以及无效 JSON。

仓库原有的 `backend/benchmark/results/benchmark_results.json` 保留为历史基线，已明确标记 `historical_baseline`。它不作为当前版本的模型验收或论文数值。正式报告应使用网页重新运行并导出的实验集，或运行完整 CLI Benchmark 生成带有新时间戳与数据集范围的结果；本轮未重新计算原先全部 37 组大型离线基准。

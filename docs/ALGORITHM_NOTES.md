# 自主实现算法说明

## Softmax 多分类逻辑回归

对每个类别学习一组线性权重，以 Softmax 将得分归一化为概率。训练目标为交叉熵与 L2 正则项之和，使用全批量梯度下降。实现中先减去每行最大得分，避免指数上溢。

## K 近邻

训练阶段保存样本；预测时计算欧氏距离并取最近的 K 个样本。默认使用距离倒数加权投票，使更近的邻居贡献更大。特征标准化对该模型尤其重要。

## 高斯朴素贝叶斯

对每个类别和特征估计均值、方差与先验概率。在条件独立假设下累加对数似然，选择后验概率最大的类别。方差平滑避免常量或近常量特征造成数值不稳定。

## CART 决策树

在每个节点遍历候选特征和阈值，选择加权基尼不纯度下降最大的划分。最大深度、最小分裂样本数和叶节点最小样本数共同限制过拟合。连续特征候选值很多时使用分位数压缩候选阈值，以平衡质量与运行速度。

## 线性支持向量机

以一对多方式构造多分类目标，最小化平均合页损失与 L2 正则项。使用带衰减的全批量次梯度下降。它在标准化后的高维数据上通常具有较好的泛化能力。

## 公平比较约定

同一次实验内，所有算法共用数据划分与随机种子；需要标准化时，每个训练折独立拟合均值和标准差。分类结果统一输出 Accuracy、Macro Precision、Macro Recall 与 Macro F1。交叉验证输出每折分数，并用全部 out-of-fold 预测计算总体指标。
